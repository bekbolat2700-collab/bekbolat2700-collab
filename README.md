## 🛡️ What I Build

**ansible-security-monitor** — A production-grade DevSecOps pipeline built from scratch:

- **Trivy** — container and IaC scanning
- **KICS** — multi-IaC security (Ansible, Helm, Dockerfile, K8s)
- **Conftest + OPA Gatekeeper** — Policy as Code enforcement
- **AI Security Gatekeeper** — contextual finding prioritization via Groq/Llama 3
- **Grafana + Prometheus** — unified security dashboard
- **HashiCorp Vault** — secrets management
- **GitHub Actions** — fully automated CI/CD pipeline

Every push triggers a full security scan. One unified report. One Telegram alert if something breaks.
